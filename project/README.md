# 🌱 ESG Analytics Platform

A professional quantitative analytics web application comparing ESG and classic portfolios using multi-factor models, tail risk analysis, and AI-powered insights.

---

## 🚀 Quick Start

### 1. Install dependencies
```bash
cd esg_app
pip install -r requirements.txt
```

### 2. (Optional) Set your Anthropic API key
```bash
cp .env.example .env
# Edit .env and add your key
export ANTHROPIC_API_KEY=your_key_here
```

### 3. Run the app
```bash
streamlit run app.py
```

## 📊 Features by Tab

### 1. Overview
- Rebased cumulative performance chart (ESG vs Classic vs Market)
- Interactive radar chart of risk-adjusted metrics
- Side-by-side metric comparison table with outperformance arrows

### 2. Risk Analysis
- Underwater/drawdown chart
- Return distribution histograms with VaR markers
- Rolling volatility, beta, and correlation vs market
- VaR & CVaR at 90%, 95%, 99% confidence
- Full statistical moments (mean, std, skewness, kurtosis, Jarque-Bera)

### 3. Factor Models
- CAPM, Fama-French 3, 5, and 5+Momentum regressions
- HAC-robust standard errors (Newey-West)
- Factor loading comparison with significance flags
- Annualised alpha with t-stats and p-values

### 4. Volatility Regimes
- High/Low volatility classification (top quartile of rolling vol)
- Performance metrics by regime: return, vol, beta, Sharpe, MaxDD, CVaR
- Cumulative return chart with high-volatility periods highlighted
- AI commentary on regime behavior

### 5. Fundamentals (single stock)
- Valuation: EV/EBITDA, EV/EBIT, P/E
- Profitability: ROE, ROA, ROIC
- WACC decomposition with interactive inputs (Rf, ERP, tax rate)
- Waterfall chart of WACC components

### 6. LBO / Private Equity
- Full LBO model: entry/exit equity, MOIC, IRR
- Debt amortisation and cash flow simulation
- MOIC sensitivity to entry multiple (chart)

### 7. AI Analysis (Claude)
- Full portfolio comparison report generated by Claude
- AI interpretation of factor model alpha
- Regime analysis commentary
- Quick insight prompts for specific questions

## 🧮 Mathematical Framework

### Returns
- **Simple:** R = (V_t - V_{t-1}) / V_{t-1}
- **Log:** r = ln(V_t / V_{t-1})

### Risk Metrics
- **Volatility:** σ = √(Var(R)) × √252
- **Beta:** β = Cov(R_p, R_m) / Var(R_m)
- **VaR:** P(R < VaR) = 1 - α
- **CVaR:** E[R | R < VaR]
- **Skewness:** E[(R-μ)³] / σ³
- **Kurtosis:** E[(R-μ)⁴] / σ⁴

### Performance Ratios
- **Sharpe:** (R_p - R_f) / σ_p
- **Sortino:** (R_p - R_f) / σ_downside
- **Treynor:** (R_p - R_f) / β_p
- **Calmar:** Ann. Return / |Max Drawdown|

### Factor Models
- **CAPM:** R_e = α + β(MKT) + ε
- **FF3:** R_e = α + β₁(MKT) + β₂(SMB) + β₃(HML) + ε
- **FF5:** FF3 + β₄(RMW) + β₅(CMA) + ε
- **FF5+MOM:** FF5 + β₆(MOM) + ε

### Corporate Finance
- **WACC:** (E/V)Re + (D/V)Rd(1-T)
- **CAPM Re:** R_f + β × ERP
- **IRR:** NPV = 0 → Σ CF_t/(1+r)^t = 0
- **MOIC:** Exit Equity / Entry Equity
